# AccessProof scope

## The Unique Kernel
An offline static-source accessibility preflight that turns common HTML gaps into source evidence and review decisions before a small community team publishes.

## Who It's For
A volunteer or junior developer maintaining a small community website without a hosted scanner or browser extension installation.

## The Core Loop
Paste HTML → inspect findings and repair patterns → record human decisions → change source and rescan → export evidence.

## What Working Looks Like
A workshop registration sample has missing image alternative text, form label and button name. The tool identifies each with its original element, then tracks what disappears after a corrected source is checked.

## POC Boundary
Source-only English/Chinese browser application; inert parsing; no source rendering, scripts or fetched resources. This is not a WCAG conformance audit. Runtime layout, contrast, interaction and assistive-technology tests remain manual.

Agent-proposed under the user's autonomous multi-project request. Personal relevance and learner interview remain unestablished. The official Devpost Learn Skill Pack scope/PRD/spec structure was consulted; no interview or personal reflection is fabricated.
