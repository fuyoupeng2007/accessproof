# AccessProof PRD

## User Journey
Small website maintainer pastes their HTML, reviews source defects, records a decision, edits their own source and compares a new scan before exporting.

## Features
Meaningful names and source structure checks; inert parsing; evidence and tailored repair patterns; review status with notes; change detection across rescans; local save; Markdown/JSON export/import; bilingual interface; responsive layout.

## Screens and Layout
One workspace: source left, evidence right, followed by a manual testing checklist. Potential barriers and human prompts are separated. No aggregate accessibility score or certification.

## Acceptance
Source cannot execute or fetch resources; fixture failures and valid labels are distinguished; edit resets review status; changed source blocks export; imported review is rechecked against source; mobile has no horizontal overflow.

## Explicitly Cut
Live URL scanning, CSS evaluation, automated remediation, browser extensions, customer accounts, legal compliance claims and site monitoring.
